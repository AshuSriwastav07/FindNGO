## 📌 Overview

**FindNGO** is an open, community-oriented Android application designed to bridge the gap between citizens, donors, volunteers, and verified Non-Governmental Organizations (NGOs) operating throughout India. 

The platform aggregates authentic organization records sourced from official registries such as the [NGO Darpan Portal](https://ngodarpan.gov.in/) (Government of India) alongside community-submitted non-profit initiatives. Through an intuitive, modern interface, users can search, explore sectors, bookmark causes, and establish direct contact with NGOs to volunteer or donate.

---

## ✨ Key Features

- 🔍 **Search & Categorized Discovery:** Find organizations by name, keyword, city, state, or key sector (Child Education, Animal Welfare, Women Empowerment, Healthcare, Human Rights, Environmental Protection, and more).
- 📋 **Verified Organization Profiles:** View authentic registration details, NGO Darpan Unique IDs, trust/society classification, mission objectives, and registered physical addresses.
- 📞 **Direct Contact Integration:** One-tap action buttons to call official phone lines, compose emails, visit official web portals, or copy contact information to the clipboard.
- 📌 **Offline Bookmarking:** Save favorite organizations to a local offline SQLite database for instant access without an internet connection.
- 🤝 **Community Data Submission:** Enable non-profit organizations and developers to submit new NGO records and donation programs directly through the in-app portal.
- 🎨 **Adaptive & Modern UX:** Clean UI built with Material Design components, ViewBinding, support for light and dark themes, and responsive layouts tailored for various screen dimensions (smartphones and tablets).

## 🛠️ Architecture & Tech Stack

| Layer | Technology |
|---|---|
| **Language** | Kotlin 1.8+ |
| **Minimum Android Version** | Android 5.0 (API Level 21) |
| **Target Android Version** | Android 14 (API Level 34) |
| **Architecture Pattern** | View-driven Component Architecture with Android Jetpack |
| **Cloud Backend** | Google Firebase Realtime Database |
| **Crash Reporting** | Firebase Crashlytics |
| **Local Database** | Android SQLite (`SQLiteOpenHelper`) for offline bookmarks |
| **Image Loading & Cache** | Picasso 2.7+ |
| **UI Components & Binding** | Material Components for Android, ViewBinding, ConstraintLayout |
| **Splash Engine** | AndroidX Core SplashScreen API |

## 🔒 Security & Local Development Setup

To safeguard production systems, user privacy, and cloud infrastructure, **all sensitive keys, keystores, and credentials (including `google-services.json` and release signing keys) are excluded from this public repository.**

### Prerequisites
- **Android Studio:** Hedgehog / Iguana / Jellyfish / Koala or newer
- **JDK:** Java Development Kit 17
- **Android SDK:** Platform SDK 34 with Build Tools 34.0.0+

### Step-by-Step Setup

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/AshuSriwastav07/FindNGO.git
   cd FindNGO
   ```

2. **Configure Firebase (Required for cloud features):**
   - Create a new project in the [Firebase Console](https://console.firebase.google.com/).
   - Add an Android app with package name `com.tlc.findngo`.
   - Enable **Firebase Realtime Database** and set up appropriate security rules.
   - Download the generated `google-services.json` file.
   - Place `google-services.json` into the `app/` directory:
     ```
     FindNGO/
     └── app/
         └── google-services.json
     ```

3. **Build the Project:**
   - Open the root folder in **Android Studio**.
   - Allow Gradle to sync dependencies.
   - Build and run the app on an Android Emulator or connected physical device:
     ```bash
     ./gradlew assembleDebug
     ```
